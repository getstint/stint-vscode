# Changelog

## 0.1.5

- First release under the verified `getstint` namespace on Open VSX, for Cursor, Windsurf, VSCodium, Kiro and Trae.

## 0.1.4

- Heartbeats send only the file extension (`*.ts`), never the file name or path.

## 0.1.3

- Track AI agents runs `npx.cmd` on Windows, so it works in PowerShell even when running scripts is disabled.

## 0.1.2

- README badges that render again.

## 0.1.1

- Fix: Stint commands no longer wait on the welcome message, so Sign in works right away instead of hanging on “Activating extension”.
- Sign in opens the browser straight away and shows your code while it waits.
- Marketplace links in the README.

## 0.1.0

- Coding time by project, language, branch and editor, with the file path sent relative to the project.
- Sign in with a code approved in the browser. Shares its account with the Stint CLI.
- Today's time in the status bar.
- Offline queue shared with the CLI.
- Works in VS Code, Cursor, Windsurf, VSCodium, Kiro and Trae.
